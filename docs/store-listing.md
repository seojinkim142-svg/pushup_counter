# Google Play 스토어 등록정보 초안

## 앱 이름
FreeFit

## 짧은 설명 (80자 이내)
카메라로 푸시업·스쿼트 횟수를 자동으로 세주는 홈트 앱. 모험·루틴·대결모드까지.

## 전체 설명 (4000자 이내)

카메라 하나로 충분합니다. FreeFit은 스마트폰 카메라로 자세를 인식해서
푸시업, 스쿼트, 팔벌려뛰기 횟수를 자동으로 세주는 홈트레이닝 앱이에요.
직접 세지 않아도 되니까 운동에만 집중할 수 있어요.

■ 연습모드
시간 제한 없이 자유롭게 연습하고 싶을 때.

■ 기록모드
30초~2분 중 원하는 시간을 골라 최대한 많이 도전하세요. 자세가 흐트러진
채로 너무 오래 쉬면 탈락이에요.

■ 모험모드
슬라임 몬스터를 하나씩 클리어하며 스테이지를 깨는 재미. 3가지 운동, 5개
챕터로 구성되어 있어요.

■ 루틴모드
6주짜리 정식 푸시업 프로그램. 먼저 최대 개수를 측정해서 본인에게 맞는
난이도로 시작하고, 세트와 휴식 타이머가 알아서 진행을 이끌어줘요.

■ 대결모드
임의의 상대와 실시간 매칭! 같은 시간에 시작해서 1분 동안 누가 더 많이
하는지 겨뤄보세요.

구글 계정으로 로그인하면 모험모드 클리어 기록과 루틴모드 진행 상황이
계정에 저장되어, 기기를 바꿔도 이어서 할 수 있어요.

## 카테고리
건강/피트니스

## 콘텐츠 등급
전체이용가 (폭력적/선정적 요소 없음)

## 데이터 안전 양식 작성 가이드

Play Console → 앱 콘텐츠 → 데이터 보안 섹션에서 아래처럼 체크하시면 됩니다.

**수집하는 데이터 종류**
- 개인 정보 → 이름, 이메일 주소: **수집함**, 용도: 계정 관리, 앱 기능
- 사진 → 프로필 사진: **수집함** (Google 계정의 프로필 URL만, 앱이 직접
  촬영한 사진은 저장 안 함), 용도: 앱 기능
- 앱 활동 → 앱 상호작용(운동 기록, 클리어 스테이지 등): **수집함**, 용도:
  앱 기능

**카메라 관련**
- 카메라로 촬영한 영상/사진 자체는 **수집하지 않음** — 기기 내에서만
  실시간 분석되고 저장되지 않으므로, "사진 및 동영상" 항목에서 실제
  촬영물은 수집 대상에서 제외하고 위 항목에만 체크하면 됩니다.

**공통 옵션**
- 데이터는 암호화되어 전송됨: 예 (Supabase가 HTTPS 사용)
- 사용자가 데이터 삭제를 요청할 수 있음: 예
- 제3자와 공유: 아니오
